# Instalación


## Claude

`dist/generador-kahoot-v0.0.1.zip` es el paquete original para el flujo de
plugins de Claude Code. Instálalo mediante el mecanismo de plugins disponible en
tu versión de Claude Code.

## Requisitos para ejecutar el generador

- Python 3.
- Paquete `openpyxl` (`python -m pip install openpyxl`).
- La plantilla `KahootQuizTemplate.xlsx` incluida en el paquete.

No necesitas instalar Python si tu entorno de Claude ya proporciona ejecución de
código con acceso a esos archivos.
